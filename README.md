# Защита корпоративных ресурсов

Отчёт по лабораторной работе № 3: расследование учебной атаки в Ampire и устранение её последствий на Microsoft Exchange, GitLab и PostgreSQL.

**[Читать отчёт в Markdown](report.md)** · **[Открыть PDF](docs/lr3-report.pdf)**

Работу выполнили Рогозин Игорь, Гусейнов Тагир и Райко Матвей, группа НБИбд-01-23. Тренировка № 1041 «ЛР3 [НБИ-01-23 Alpha] v3», 14 октября 2026 года.

## Результаты

| Актив | Выполненные действия | Результат проверки |
| :--- | :--- | :--- |
| Microsoft Exchange | Ограничение ECP, удаление нелегитимного пользователя, завершение атакующего процесса | Пользователь `hacker` отсутствует; прежние процессы и соединения больше не наблюдаются |
| GitLab | Восстановление проекта, обновление до CE `13.10.3`, одобрение новых регистраций администратором | `README.md` и `main.py` восстановлены; все 15 служб запущены |
| PostgreSQL | Дешифрование и возврат файлов, смена пароля, ограничение HBA и переход на `localhost` | Четыре файла восстановлены, `diff` возвращает `0`, удалённый порт `5432` недоступен |

На итоговом экране Ampire все три уязвимости и три последствия имеют статус «Устранено».
